# Code availability

The complete RD-HDDM-GNN implementation, training pipeline, geometry-generation implementation, partition-repair implementation, and internal analysis code are not publicly distributed because of ongoing intellectual-property protection.

The public package contains data, configurations, outputs, audit statistics, pseudocode, architecture specifications, and run manifests. Editors and reviewers may request confidential access for evaluation. Any confidential delivery should be governed by the journal's review process and must not be redistributed.
