# Code availability

The complete RD-HDDM-GNN implementation, training pipeline, geometry-generation implementation, partition-repair implementation, and internal analysis code are not publicly distributed because of ongoing intellectual-property protection.

The public package contains data, configurations, outputs, audit statistics, pseudocode, architecture specifications, and run manifests. Editors and reviewers may request confidential access for evaluation. Any confidential delivery should be governed by the journal's review process and must not be redistributed.

## Public reproducibility package

The datasets, YAML configurations, mesh and partition information, model
predictions, aggregate evaluation results, audit outputs, figure source data,
and methodological documentation are publicly archived at:

- Zenodo: https://doi.org/10.5281/zenodo.22769372
- GitHub: https://github.com/rshioya/rd-hddm-gnn

The source code implementing RD-HDDM-GNN is not publicly available because of
ongoing intellectual-property protection. The code may be made available to
editors and reviewers for confidential evaluation upon reasonable request.
