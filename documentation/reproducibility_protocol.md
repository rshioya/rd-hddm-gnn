# Reproducibility protocol

Record the frozen values for: dataset composition, geometry families, splits, mesh generation parameters, 24 sensor-node indices, normalization, random seeds, epochs, batch size, optimizer, learning rate, weight decay, scheduler, early stopping, gradient clipping, correction scale, Part count, software versions, GPU, CPU, memory, and operating system.

The prospective geometry families must be identified separately from the development families. The manifest must link each reported result to its configuration, seed, checkpoint identifier, geometry family, prediction file, and aggregate metric file.
